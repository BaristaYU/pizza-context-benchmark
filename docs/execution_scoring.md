# 제작 실행의 채점

채점은 **주문 요구조건 충족**과 **주어진 계획의 이행**을 평가합니다. 문항별 결과는 통과와 실패뿐이며, 점수형 보조 지표는 두지 않습니다. GUI와 CLI는 같은 제작 상태와 채점기를 사용합니다.

## 최종 주문: outcome

`pizzabench/grading.py`의 `evaluate(Answer, Execution)`이 최종 State를 Answer와 비교합니다. 문항별 결과는 `passed: true/false`와 오류 목록입니다. 여러 문항의 주문 성공률은 통과 문항 수를 전체 문항 수로 나눈 값입니다.

| 조건 | 검사 |
| --- | --- |
| 제출 | 생성되어 남아 있는 피자가 모두 포장·제출됐는가 |
| 판수 | Answer에 판수가 있으면 정확히 같은가 |
| 재료 | 지정된 토핑 종류가 정확히 일치하는가. 요구 토핑마다 최소 한 조각이 있는가 |
| 수량 | 지정한 종류별·전체·반쪽별 수량 또는 범위를 만족하는가 |
| 영역 | 소스·치즈·토핑 각각의 지정된 적용 영역을 만족하는가 |
| 도우·굽기·조각 수 | Answer에 지정된 속성이 일치하는가 |
| 반반 | 좌우 교환이 허용된 경우 모든 재료의 좌우 관계를 함께 교환해도 맞는가 |
| 여러 피자 | 제출 순서와 무관하게 정답 피자와 일대일로 대응되는가 |
| 대안 | Answer의 완전한 대안 중 하나를 모두 충족하는가 |

Answer에 없는 속성은 채점 조건으로 추가하지 않습니다. 소스 `any`는 소스의 종류만 자유이고 사용은 필수입니다. 토핑 수량을 지정하지 않으면 해당 종류마다 최소 한 개를 허용합니다. 가이드 격자, 균등 배치, 기본 굽기·커팅을 모든 문항의 정답 조건으로 추가하지 않습니다.

영역은 실제 좌표를 요약한 값입니다. 한쪽에만 적용됐으면 `left` 또는 `right`, 양쪽에 적용됐으면 `whole`입니다. 현재 영역 판정은 도포 면적의 최소 비율이나 가이드 충족률을 검사하지 않습니다. 토핑 좌표와 소스·치즈 격자는 State에 남아 실패 분석에 사용할 수 있습니다.

## 계획 이행: plan

`pizzabench/execution_eval.py`는 참조 계획이 제공된 실행에서 성공한 제작 호출을 비교합니다. 도구 이름·대상·인수·순서를 검사하고 빠진 행동과 추가 행동을 기록합니다. 순서를 보존하는 최장 공통 부분열로 대응시켜, 같은 행동을 여러 참조 단계에 중복 사용하지 않습니다.

- `observe`는 관측 횟수가 달라도 됩니다.
- 숫자 인수는 절대 오차 `1e-6`으로 비교합니다.
- 실패한 호출은 성공한 제작 행동 목록에 넣지 않습니다. 오류 후 같은 단계를 올바르게 재시도할 수 있습니다.
- 최종 피자는 같아도 참조와 다른 제작 인수·순서이면 plan은 실패할 수 있습니다.

이는 구체적인 호출 계획을 주는 독립 Tool Use의 현재 계약입니다. Planning에서 모델이 다른 유효한 계획을 작성한 경우에는 실행 가능성과 outcome을 확인합니다.

## 실행 진단: metrics

호출 수, 성공·실패 호출 수, 제작 호출 수, 재확인 요청 수, 시뮬레이션 시간을 기록합니다. 이 수치를 임의의 가중치로 주문 점수에 더하거나 빼지 않습니다.

독립 Tool Use의 `evaluation.passed`는 outcome과 plan을 모두 만족해야 true입니다. 참조 계획이 없는 게임에서는 outcome을 사용합니다. 기존 `score` 필드는 outcome 판정을 유지합니다.

## 구현 범위

| 평가 | 상태 |
| --- | --- |
| 최종 State와 Answer 비교 | 구현 |
| 구체적인 참조 도구 계획과 실행 비교 | 구현 |
| 호출 오류·시간·재확인 진단 | 구현 |
| L 주문서 비교 | 구현(`linguistics_form.compare`), 단계 평가 연결은 후속 작업 |
| 모델이 작성한 A의 누락·과잉 제약 비교 | 후속 작업 |
| 고수준 계획과 화면 제스처 사이의 의미적 이행 판정 | 후속 작업 |

outcome, plan, metrics를 같은 실행에 기록해 해석, 계획, 조작 중 어디에서 실패했는지 분석합니다.
